## 四、项目硬纪律（摘要，完整版见 `.workbuddy/memory/MEMORY.md` + `PITFALLS.md`）

1. 凭据绝不硬编码；行尾 blob 全 LF、改 CRLF 文件用 `newline=""`。
2. **judge-first**：先写判据跑红，再改源码转绿。
3. **改动必配判据 + 扰动**，验收 = 零哑弹（SKIP/MISS 都算哑弹）；扰动绝不并行、绝不与源码编辑同时进行。
4. 变异标记只用 `# 扰动`；扰动统一走 `_perturb_guard.arm()`。
5. **只加不减**：不改既有判据的结论；fail-open：异常一律退回改动前行为。
6. 排除类判断用**后向/位置判据或闭集豁免**，反对前向白名单枚举（开集补不完）。
7. 行为级断言，不查源码字符串（静态串判据恒真，踩过 P9/P33）。
8. `git push` 裸推 `origin main`，成败只比 sha；**默认不 push，大哥说「推」才推**。
9. 军团改造只碰 legion 相关文件，绝不动主对话模块（本轮改意图层是大哥明确授权）。
